# 末日生存文字游戏平台｜关键格式与代码规范（v1）

## 1. 目标
- 统一项目中的关键数据格式、命名规范、错误码、日志格式与代码模板。
- 降低多人协作时的接口偏差和状态一致性问题。

---

## 2. 关键枚举与命名规范

### 2.1 枚举值
- Difficulty: `SEEKER | SURVIVOR | HELL`
- RiskLevel: `VERY_LOW | LOW | MEDIUM_LOW | MEDIUM | MEDIUM_HIGH | HIGH | VERY_HIGH`
- AgentName: `RouterAgent | RetrievalAgent | DifficultyDirectorAgent | PlotGenerationAgent | OptionGenerationAgent | RuleGuardAgent | StateCommitAgent | NarrationAgent`
- JobStatus: `PENDING | RUNNING | DONE | FAILED`

### 2.2 命名约定
- Java 类名：大驼峰，如 `GameSessionController`
- Java 字段：小驼峰，如 `expectedVersion`
- DB 表名：下划线小写，如 `game_session`
- JSON 字段：小驼峰，如 `challengeIndex`

## 5. Redis Key 规范
- 会话状态：`game:{sessionId}:state`
- 会话版本：`game:{sessionId}:version`
- 回合快照：`game:{sessionId}:turn:{turn}`
- 幂等去重：`idem:{sessionId}:{idempotencyKey}`
- 挑战缓存：`challenge:{sessionId}:index`
- 翻盘卡次数：`game:{sessionId}:comeback-card`

TTL 建议：
- 幂等 key: 24h
- 回合快照: 7d（再异步归档）

## 7.3 Controller 示例（Java）
```java
@RestController
@RequestMapping("/api/v1/game/sessions")
public class GameSessionController {

    private final GameTurnService gameTurnService;

    public GameSessionController(GameTurnService gameTurnService) {
        this.gameTurnService = gameTurnService;
    }

    @PostMapping("/{sessionId}/turns")
    public ApiResponse<SubmitTurnResponse> submitTurn(
            @PathVariable String sessionId,
            @RequestHeader("Idempotency-Key") String idempotencyKey,
            @RequestBody SubmitTurnRequest request
    ) {
        var traceId = TraceIdHolder.getOrCreate();
        var data = gameTurnService.submitTurn(sessionId, idempotencyKey, request, traceId);
        return ApiResponse.ok(data, traceId);
    }
}
```

## 7.4 前端类型与调用（TypeScript）
```ts
export interface ApiResponse<T> {
  code: string;
  message: string;
  data: T;
  traceId: string;
  timestamp: number;
}

export interface SubmitTurnRequest {
  expectedVersion: number;
  playerInput: string;
  clientTime: number;
}

export async function submitTurn(
  sessionId: string,
  payload: SubmitTurnRequest,
  idempotencyKey: string,
) {
  return http.post<ApiResponse<SubmitTurnResponse>>(
    `/api/v1/game/sessions/${sessionId}/turns`,
    payload,
    { headers: { "Idempotency-Key": idempotencyKey } },
  );
}
```

## 8. Prompt 模板规范（Agent）

Plot Generation Agent 模板要点：
- 你必须使用第二人称“你”叙事。
- 你必须遵守给定规则与状态，不得虚构未授权事实。
- 你需要生成 220-420 字剧情文本。
- 你必须输出 JSON，不得输出解释性文本。

Option Generation Agent 模板要点：
- 固定输出 4 个选项：激进、稳健、资源导向、探索导向。
- 每个选项需包含 riskLevel 与 expectedEffect。
- 禁止输出违反 RuleGuard 的非法选项。
